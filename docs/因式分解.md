# 初中因式分解总结

## 一、什么是因式分解
把一个多项式写成几个整式相乘的形式。

例：
$x^2 - 9 = (x - 3)(x + 3)$
---

## 二、常见因式分解方法

### 1. 提公因式法
把多项式中共同的因式提出来。
例：
$3x + 6 = 3(x + 2)  $
$2x^2 + 4x = 2x(x + 2)$

---

### 2. 平方差公式

公式：
$a^2 - b^2 = (a - b)(a + b)$

例：
$x^2 - 16 = (x - 4)(x + 4)$
$9a^2 - b^2 = (3a - b)(3a + b)$
---

### 3. 完全平方公式
公式：
a^2 + 2ab + b^2 = (a + b)^2  
a^2 - 2ab + b^2 = (a - b)^2

例：
x^2 + 6x + 9 = (x + 3)^2  
a^2 - 4a + 4 = (a - 2)^2

---

### 4. 十字相乘法（二次三项式）
适用于：ax^2 + bx + c

步骤：
1. 分解 a 和 c  
2. 找两个数，使乘积 = ac，和 = b  

例1：
x^2 + 5x + 6  
= (x + 2)(x + 3)

例2：
2x^2 + 7x + 3  
= (2x + 1)(x + 3)

---

### 5. 分组分解法
例：
x^2 + ax + bx + ab  
= x(x + a) + b(x + a)  
= (x + a)(x + b)

---
